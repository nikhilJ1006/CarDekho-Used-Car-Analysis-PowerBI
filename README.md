# CarDekho Used-Car Listing & Price Analysis

## Project Overview
An interactive Power BI project analysing used-car listings, listed prices, vehicle age, ownership, fuel type, and car-model patterns.

## Objectives
- Analyse the distribution of used-car listings.
- Compare average and median listed prices.
- Understand the relationship between vehicle age and listed price.
- Compare listing frequency and prices across car models.

## Tools Used
- Microsoft Power BI
- DAX
- CSV dataset

## Report Pages
1. **Executive Overview** — listing KPIs, fuel distribution, and price segments.
2. **Price & Condition** — listed prices by vehicle age and ownership.
3. **Model Benchmarking** — frequently listed models, average listed prices, and selected-car details.

## Important Note
The dataset represents used-car listings. Listed prices are asking prices, not confirmed transaction prices or completed sales.
